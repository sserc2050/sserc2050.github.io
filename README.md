# S.S.E.R.C. Website (GitHub Pages)

A responsive, dark-mode recruitment/participation landing page for the fictional Suriname Space Exploration Research Center, with Suriname-inspired navy, red, gold and pale accents.

## Included
- Responsive layout (desktop/tablet/mobile)
- Dutch default language with English toggle
- Eight role cards, each with a WhatsApp application link
- Pre-filled WhatsApp messages specifying the role and that participation is currently volunteer-only
- General Apply CTA
- No build step or external JavaScript libraries required

## WhatsApp setup
The website uses `+597 874 3042` (Suriname country code included) in `script.js`. Confirm this is the intended number before publishing.\n

## Publish on GitHub Pages
1. Create or open your GitHub repository.
2. Upload the contents of this folder (not the folder wrapper) to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish; your site URL will appear on the Pages settings screen.


## Notes
This is a fictional space agency / modelling project concept. The roles are creative modelling participation roles, not actual employment or operational aerospace positions. All roles are currently volunteer roles.
